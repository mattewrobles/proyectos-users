## Cómo duplicar una sección MC

```javascript
// Patrón: clonar una sección existente y posicionarla
const page = figma.root.children.find(p => p.name === '↳ Multi-carrier by Meaningful');
await page.loadAsync();

// Navegar hasta el frame de la sección latest
const section = await figma.getNodeByIdAsync('2242:249'); // SECTION July 2025
const mainFrame = section.children.find(f => f.name === 'Multi-carrier Shipping Software Landing');

// Clonar sección específica (ej: testimonials id:2242:609)
const testimonials = mainFrame.children.find(f => f.id === '2242:609');
const clone = testimonials.clone();
page.appendChild(clone);
```
