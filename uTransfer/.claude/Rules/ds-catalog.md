## Regla de uso al diseñar ⚠️

**Las pantallas se diseñan en Figma usando la librería `Utransfer_D_S`** — no en React.

Antes de construir cualquier pantalla en Figma:
1. Revisar este catálogo para identificar qué componentes existen en la librería
2. Usar siempre `importComponentByKeyAsync` con las keys de `ds-components.md` — nunca crear frames custom si hay un componente en la librería
3. Nunca inventar un componente si ya existe en `Utransfer_D_S`
4. Los componentes ✅ también tienen implementación React/Storybook (para el design system web en paralelo)
